# 架构设计文档

## 1. 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                      客户端 (测试脚本)                        │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    FastAPI RESTful API                       │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐          │
│  │  认证中间件  │  │  日志中间件  │  │  异常处理   │          │
│  └─────────────┘  └─────────────┘  └─────────────┘          │
│                                                              │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                    API 路由层                        │    │
│  │  /api/v1/sheets/*  │  /health  │  (扩展模块...)     │    │
│  └─────────────────────────────────────────────────────┘    │
│                              │                               │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                    服务层 (Services)                 │    │
│  │  SheetService  │  WeComService  │  (扩展服务...)    │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    企业微信 API                              │
│              (在线表格读写、认证授权)                         │
└─────────────────────────────────────────────────────────────┘
```

## 2. 模块划分

| 模块 | 职责 | 文件 |
|------|------|------|
| API层 | 路由定义、参数校验、响应格式化 | api/*.py |
| 服务层 | 业务逻辑、外部API调用 | services/*.py |
| 核心层 | 认证、日志、异常处理 | core/*.py |
| 模型层 | 数据模型定义 | models/*.py |

## 3. 扩展性设计

系统采用插件化架构，新增功能模块只需：
1. 在 `services/` 下创建新服务
2. 在 `api/` 下创建新路由
3. 在 `main.py` 中注册路由

预留扩展点：
- 数据库模块：`services/database.py`
- TFS集成：`services/tfs.py`
- 缓存模块：`services/cache.py`
